# INEW 1340 Course Repository

This repository holds all of your work for INEW 1340 (ASP.NET Programming) at Midland College.

## Folders you will create

| Folder | What goes in it | Created in |
|---|---|---|
| `CertTrack` | Your semester project | Module 1 |
| One folder per Code-Along, such as `DailySpecial` | The small practice apps you build each week | Each module |

## Opening this repository

- In GitHub Codespaces: click Code, then the Codespaces tab, then Create codespace on main.
  Everything you need (.NET 10 and the C# Dev Kit) installs on its own the first time.
- On your own computer: install the .NET 10 SDK, Visual Studio Code, the C# Dev Kit extension, and Git,
  then clone this repository. The Start Here module in Canvas walks you through both options.

## Turning in your work

Commit and push to this repository before each due date. Your instructor grades the last commit pushed before the due date.
